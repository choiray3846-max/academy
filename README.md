# 학원 지점 달력

여러 지점을 운영하는 학원을 위한 달력 웹앱입니다. 서버 없이 브라우저(localStorage)에 저장되는 프론트엔드 전용 앱이라, 정적 호스팅(GitHub Pages, Netlify 등)에 올리기만 하면 바로 쓸 수 있습니다.

이 저장소에는 달력 외에 독립 실행되는 앱이 더 있습니다.

- [`timetable/`](timetable/) — 좌석 시간표 (자동 배치 지원)
- [`payslip/`](payslip/) — 알바 급여 명세서 (근무 기록 → 주휴·연장·야간·공제 자동 계산, 인쇄)

## 주요 기능

- **월간 / 주간 달력** — 지점별 색상, 대한민국 공휴일 표시, 오늘·선택일 강조, 인쇄 지원
- **학원 행사·일정** — 시험, 설명회, 휴원, 특강 등 분류별 등록. 여러 날짜에 걸치는 기간 일정과 전 지점 공통 일정 지원
- **강사 근무·휴무·대강** — 강사별 색상으로 표시, 대강은 누구 대신인지 기록
- **상담 예약** — 지점·담당자·상태(예약/완료/취소/노쇼) 관리, 같은 시간대 중복 예약 경고
- **화면 모드(역할)** — 원장·본사 / 지점 관리자 / 강사 / 학부모·학생 모드
  - 지점 관리자는 자기 지점만, 강사는 본인 일정만, 학부모·학생은 공개 일정만 보입니다
  - 안내 태블릿 등을 위해 관리자 복귀 시 PIN을 요구하도록 설정 가능
- **필터·검색** — 지점, 항목 종류(행사/근무/상담), 키워드로 좁혀 보기
- **백업·복원** — JSON 파일로 내려받기/불러오기 (기기 간 이동용)
- **다크 모드** — 시스템 설정 따라가기 또는 수동 선택

> **수업 시간표**: 이 학원의 수업은 일반적인 '매주 같은 요일·시각' 형태가 아니라서 아직 달력에서 빼 두었습니다.
> 도메인 로직(`src/lib/schedule.ts`의 `CLASS_MODULE_ENABLED`)은 준비되어 있으므로,
> 운영 방식이 확정되면 스위치를 켜고 수업 등록 화면만 붙이면 됩니다.

## 시작하기

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드 (dist/)
```

처음 열면 예시 데이터가 들어 있습니다. 실제로 쓸 때는
**학원 관리 → 백업·초기화 → 전체 초기화** 후 지점·강사를 등록하세요.

## 데이터 저장 방식

- 모든 데이터는 현재 브라우저의 localStorage에 저장됩니다 (`academy-calendar/data`)
- 다른 컴퓨터와 공유하려면 **학원 관리 → 백업·초기화**에서 JSON으로 내보내고 불러오세요
- 나중에 서버를 붙일 경우 `src/lib/storage.ts`의 load/save만 교체하면 됩니다

## 코드 구조

```
src/
  types.ts            도메인 타입 (지점·강사·행사·근무·상담…)
  lib/
    date.ts           날짜·시간 유틸 (타임존 안전한 YYYY-MM-DD 처리)
    holidays.ts       대한민국 공휴일 표
    schedule.ts       일정 전개·필터·역할별 가시성·중복 검사
    storage.ts        localStorage 저장/백업 (서버 교체 지점)
  data/seed.ts        첫 실행용 예시 데이터
  store/AppStore.tsx  React 컨텍스트 (자동 저장, 다중 탭 동기화)
  components/         달력·폼·관리 화면 UI
```
