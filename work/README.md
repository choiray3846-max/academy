# 상계2점 업무관리

구글 시트 '통합 업무관리'를 대신하는 웹앱. 빌드 없이 정적 파일(`index.html`, `app.js`, `sync.js`, `app.css`)만으로 돌아간다.
배포 주소: https://choiray3846-max.github.io/academy/work/

## 화면

- **표** — 시트처럼 매니저·학생·학교·학년·등원·졸음/전자기기·학생 이슈·학부모 이슈·기간 이슈를 한 화면에. 칸에서 바로 입력, 화살표/Tab 이동. 하루·7일·30일 보기
- **오늘** — 폰에서 쓰기 편한 목록. 학생별 O/X, 눌러서 이슈 메모
- **학생** — 명단, 담당 매니저 필터, 상태색(위험·주황·집중·초록·좋음), 기록 타임라인
- **이슈** — 모든 이슈 메모를 최신순으로
- **요청** — 받는 사람을 지정해 부탁, 처리되면 체크
- **달력** — 지점달력(`calendar:학원코드`)의 행사·휴원·상담·근무를 읽기 전용으로 보여주고, 이 앱의 학생 기간 이슈와 그날 출결 집계를 함께 표시
- **설정** — 여러 기기 공유(Supabase), 직원 관리, 내 이름, 백업 내려받기/불러오기

## 데이터

- 기본은 브라우저 localStorage(`academy-work/data`)
- 설정에서 Supabase를 연결하면 `boards` 테이블에 `work:학원코드`(직원·학생·기간이슈·요청)와 `work:학원코드:d:YYYY-MM-DD`(하루 일지) 행으로 저장
- 달력·급여 앱과 같은 사이트라 그 앱들의 공유 설정(`academy-calendar/sync` 등)이 있으면 자동으로 가져다 쓴다
- 동시 편집은 '마지막 저장이 이긴다'가 아니라 **학생별·칸별로 더 최근 것**을 합치므로 매니저 여럿이 같은 날을 같이 적어도 서로 지우지 않는다
- 작성자 태그(`[이CM]`, `[TM]`, `[원장]`, `[코디]`)는 새로 쓸 때 자동으로 붙고, 글씨색은 예전 시트 규칙을 따른다

학생 이름·상담 내용이 들어가는 명단 파일은 이 저장소에 넣지 않는다. 설정 → 백업 불러오기로 각자 넣는다.
