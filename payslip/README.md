# 알바 급여 명세서

학원 알바(파트타임) 직원의 출퇴근을 기록하면 월별 급여명세서를 자동으로 만들어 주는 웹앱입니다.
달력 앱과 마찬가지로 서버 없이 브라우저(localStorage)에 저장되는 프론트엔드 전용 앱입니다.

## 주요 기능

- **직원 관리** — 이름·시급·공제 방식(3.3% / 4대보험 / 없음)·지급 계좌. 그만둔 직원은 보관 처리
- **근무 기록** — 세 가지 방식 중 선택. 달력에서 여러 날을 골라 한 번에 등록
  - **수업 횟수** (기본): 하루 수업 1회 = 1시간 30분, 2회 = 3시간 근무로 환산 (회당 시간은 설정에서 변경)
  - **출퇴근 시각**: 시각·휴게시간 입력, 자정 넘는 근무(퇴근이 출근보다 빠르면 다음 날) 지원
  - **DC 업무**: 시간만 입력하고 직원별 DC 시급으로 따로 계산
  - **금액 직접 입력**: 일반적이지 않은 경우, 그날 급여를 금액으로 바로 입력
  - 기록마다 **지각** 표시 가능 — 지각한 날은 준비시간에서 15분(설정에서 변경) 차감
- **자동 계산**
  - 기본급 = 근무시간 × 시급
  - 준비시간 = 출근한 날마다 30분(설정에서 변경) × 직원별 준비 시급(비우면 기본 시급).
    직원마다 적용 여부를 켜고 끌 수 있음
  - DC 업무 = 기록한 시간 × 직원별 DC 시급(비우면 기본 시급)
  - 주휴수당 = 주(월~일) 15시간 이상 일한 주에 `min(주 시간, 40h) / 40 × 8h × 시급`.
    주 시간에는 근무(연장 제외)뿐 아니라 DC 업무·준비시간도 포함
  - 연장근로(1일 8시간·주 40시간 초과)·야간근로(22~06시) 가산 50% — **상시 5인 이상 사업장 설정 시에만**
  - 공제: 3.3% 원천징수(소득세 3% + 지방세 0.3%) 또는 4대보험 근로자 부담분(요율은 설정에서 수정)
- **명세서 인쇄** — 직원별 또는 전체 일괄. 브라우저 인쇄로 종이/PDF 저장
- **추가 지급·공제** — 상여금, 근로소득세(간이세액) 등 손으로 넣는 항목
- **백업·복원** — JSON 내려받기/불러오기

## 계산 규칙 (알아 둘 것)

- 기본급은 **근무한 날짜**가 속한 달에 들어갑니다.
- 연장·주휴처럼 주 단위로 계산되는 항목은 **그 주 일요일이 속한 달**의 명세서에 들어갑니다.
  (달을 걸치는 주도 한 번만, 빠짐없이 반영하기 위한 규칙입니다)
- 야간시간은 시각 구간(22~06시)과 겹치는 만큼 계산하고, 휴게시간은 근무시간 비율로 차감합니다.
  수업 횟수로 기록한 날은 시각 정보가 없으므로 야간시간을 계산하지 않습니다.
- 준비시간은 출근일마다 붙는 수당으로, 주휴 계산에는 들어가고 연장 계산에는 넣지 않습니다.
  같은 날 근무 기록이 여러 건이어도 준비시간은 하루 한 번만 붙습니다.
  DC 업무만 있는 날도 출근일로 세어 준비시간이 붙습니다.
- DC 업무 급여는 DC 시급으로 따로 계산하며, 시간은 주휴 계산에 포함하고 연장 계산에는 넣지 않습니다.
- 직접 입력한 금액은 그대로 지급하고 준비시간·주휴·연장 계산에는 넣지 않습니다.
- 세금·보험료는 10원 미만 절사합니다.
- 국민연금 기준소득월액 상·하한, 근로소득 간이세액표는 반영하지 않습니다.
  필요하면 명세서의 **추가 지급·공제**로 직접 조정하세요.
- 최저시급(기본 2026년 10,320원)보다 낮은 시급은 경고를 띄웁니다. 설정에서 바꿀 수 있습니다.

## 시작하기

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드 (dist/)
```

## 코드 구조

```
src/
  types.ts              도메인 타입 (직원·근무 기록·조정 항목·설정)
  lib/
    date.ts             날짜 유틸 (주 시작·월 계산)
    payroll.ts          급여 계산 (연장·야간·주휴·공제) — 핵심 로직
    format.ts           금액·시간 표기
    storage.ts          localStorage 저장/백업
  components/
    WorkTab.tsx         근무 기록 입력·주별 요약
    PayslipTab.tsx      명세서 렌더링·인쇄·추가 항목
    EmployeesTab.tsx    직원 관리
    SettingsModal.tsx   사업장·요율 설정
    BackupModal.tsx     JSON 백업·복원·초기화
```
